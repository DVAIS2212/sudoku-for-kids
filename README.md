# סודוקו לילדים (Sudoku for Kids)

A friendly sudoku game in Hebrew that teaches kids how to play. It's a single web page that works on iPhone, iPad and computers.

## Levels

| Level  | Board sizes  |
|--------|--------------|
| Easy   | 4×4 or 6×6   |
| Medium | 6×6 or 9×9   |
| Hard   | 9×9          |

## Made for learning

- **How to play** walkthrough (❓) explains rows, columns and boxes with a little example board.
- **Owl clues** (💡): the first tap shows where to look, the second tap fills it in and explains *why*.
- **Wrong answers explain themselves**: "There's already a 🐱 in this row."
- **Notes pencil** (✏️) for writing small guesses, like real sudoku players.
- Every puzzle can be solved by plain logic, with no guessing.

## Just for fun

- Play with numbers or animals 🐶
- Colored boxes, sounds, confetti and star ratings
- Sticker book: earn a sticker for every puzzle you solve
- Suggests the next challenge when a puzzle goes well
- Remembers the game in progress

## Add it to the home screen (iPhone / iPad)

Open the link in Safari → tap the Share button → **Add to Home Screen**. It then opens full screen like an app.
